# Java Mini Game Projects 🎮

A collection of **Java-based desktop game applications** developed using **Java Swing and AWT**, demonstrating strong fundamentals in **object-oriented programming, event-driven architecture, and GUI development**.

This repository contains multiple interactive games built to practice **core Java concepts, game logic, and UI handling**.

---

## 📌 Projects Included

### 1️⃣ Number Guessing Game
- A GUI-based game where the user guesses a randomly generated number between 1 and 100.
- Provides real-time feedback (Too High / Too Low / Correct).
- Tracks number of attempts and handles invalid inputs gracefully.

**Key Concepts Used:**
- Java Swing components
- Exception handling
- Random number generation
- Event listeners

---

### 2️⃣ Rock Paper Scissors
- Classic Rock–Paper–Scissors game played against the computer.
- Displays real-time results and maintains user vs computer score.
- Clean UI layout with responsive button-based input.

**Key Concepts Used:**
- Event-driven programming
- Conditional logic
- Randomized computer moves
- GUI layout management

---

### 3️⃣ Snake Game
- Fully functional Snake game with keyboard controls.
- Real-time movement using timers.
- Collision detection with walls and self.
- Dynamic food generation and score tracking.
- Reset functionality after game over.

**Key Concepts Used:**
- Game loop using `Timer`
- Keyboard event handling
- Collision detection
- 2D graphics rendering
- State management

---

## 🛠️ Technologies Used
- **Language:** Java
- **GUI Framework:** Swing, AWT
- **IDE:** VS Code / IntelliJ IDEA (or any Java-supported IDE)
- **Build Tool:** Java Compiler (`javac`)

## ▶️ How to Run

1. Clone the repository:
```bash
git clone https://github.com/your-username/Java_projects.git
```
2. Navigate to the project folder:
```bash
cd Java_projects
```
3. Compile and run any game:
   ```bash
   javac FileName.java
   java FileName
  ```
